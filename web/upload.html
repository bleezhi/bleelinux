Stages .bleepkg files into the packages repo, then triggers the packages workflow to index and publish them — no CLI needed. Token stays in this page's memory only, never stored.

Why staging? uploads.github.com sends no CORS headers, so browsers can't POST release assets directly. Staging goes through api.github.com (CORS-enabled); CI does the release upload.

Token needs contents:write + actions:write (classic PAT: repo + workflow).
